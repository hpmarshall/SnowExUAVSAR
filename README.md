# SnowExUAVSAR — Mores Creek Summit UAVSAR/lidar pilot

Builds a 3 m analysis-ready datacube of SnowEx UAVSAR InSAR and lidar products over
Mores Creek Summit (MCS), Idaho, retrieves per-pair ΔSWE maps from atmosphere-corrected
phase, validates them, and ranks the pairs most useful for defining sub-km precipitation
patterns for snow-model input. Runs under the conda env `myenv` — see **Environment** in
`AGENTS.md` (`environment.yml` recreates it; note the `PROJ_DATA` gotcha there).

Deliverables for the snow modeling team: `mcs_zarr_userguide.pdf`,
`mcs_summary_report.pdf`, and the subset file `ZARR/mcs_top_pairs_subset.nc`
(regenerated by `export_subset_nc.py`).

## Catalog / search (SnowEx-wide, phase 1 of the project)

| file | what it is |
|---|---|
| `find_snowex_flights.py` | Queries ASF (asf_search) for all UAVSAR flights, winters 2014–2021 + 2016–17 extension, western US; writes `snowex_uavsar_flights.csv` + `flight_table.md` |
| `find_snowex_lidar.py` | Catalogs SnowEx/ASO airborne lidar (NSIDC CMR + local archives); writes `snowex_lidar_flights.csv`, `lidar_table.md`, `snowex_lidar.kml` |
| `download_lidar_archive.py` | Resumable downloader for all cataloged lidar products into `LIDAR/` (git-ignored) |
| `make_flightline_kml.py` | UAVSAR flight lines → `snowex_flightlines.kml` |
| `make_overlap_kml.py` | Lidar–UAVSAR overlaps (≤3 months apart) → `snowex_overlap.kml`, `snowex_overlap.csv`, `overlap_table.md` |
| `flight_table.md`, `snowex_uavsar_flights.csv` | All UAVSAR flights found (location, state, date, heading) |
| `lidar_table.md`, `snowex_lidar_flights.csv`, `snowex_lidar.kml` | All SnowEx-relevant lidar acquisitions |
| `overlap_table.md`, `snowex_overlap.csv`, `snowex_overlap.kml` | Lidar–UAVSAR temporal/spatial overlaps |
| `snowex_flightlines.kml` | KML of UAVSAR flight lines |
| `MCS_domain.kml` | The Mores Creek Summit area of interest |

## MCS datacube build chain (order matters)

| file | what it does |
|---|---|
| `uavsar_pair_manifest_mcs.json` | The 22 MCS InSAR pairs (scene name, URL, line, dates, heading) — defines the Zarr's `pair` dimension order |
| `build_mcs_datacube.py` | Builds `ZARR/mores_creek_summit.zarr`: regrids all MCS lidar (0.5→3 m block-average) and every pair's wrapped/unwrapped phase + coherence (complex-domain regrid for wrapped) onto one 3 m UTM grid; defines the canonical grid constants other scripts import; pol-file matching is product-version-agnostic (`L090{pol}_NN`) |
| `reingest_pair.py` | Re-processes one pair and region-writes it into the existing Zarr + GUI NetCDF without a rebuild (used to recover the `_L090_02` pair after the version-filter fix) |
| `compute_local_incidence_angle.py` | Per-line local incidence angle from JPL Stack .llh/.lkv look vectors + the 2023-02-09 lidar DTM (segment-aware, replacing a shape bug in uavsar_pytools); appends `lia` |
| `compute_atm_delay.py` | ERA5 (phase_o_matic) atmospheric phase delay integrated *below aircraft altitude*, per flight; appends `atm_delay`; caches ERA5 + flight times (`atm_delay_flight_times.json`, `atm_delay_run.log`) |
| `compute_atm_delay_diff.py` | Per-pair delay difference (date2 − date1) matching `unwrapped_phase`; appends `atm_delay_diff` |
| `unwrap_missing_pairs.py` | SNAPHU (smooth/MCF, 5×5 looks, 2π-snapped back to 3 m) unwrapping of the 5 pairs ASF ships no `.unw.grd` for (9, 12, 14, 20, 21); QC figures `unwrap_qc_pair*.png`; provenance attrs on the Zarr |
| `atm_delay_flight_times.json` | Cached precise UTC acquisition time per flight (from ASF) |
| `atm_delay_run.log` | Log of the atmospheric-delay production run |

## Retrieval, validation, ranking

| file | what it does |
|---|---|
| `compute_phase_sd_correlations.py` | Screening: lidar snow depth vs unwrapped (Pearson) and wrapped (Mardia circular–linear) phase, 90 m blocks; → `phase_sd_correlations.{md,csv}`; also exports the shared `block_mean`/`pearson` helpers |
| `compute_dswe.py` | ΔSWE retrieval: atmosphere-corrected phase → Guneriussen-2001 inversion (ρ=250, real LIA), coherence mask, planar deramp for `DERAMP_PAIRS` (elevation term kept), SNOTEL anchor; appends `dswe` to Zarr + GUI NetCDF; → `dswe_retrieval_log.csv`, `deramp_pair8.png` |
| `validate_dswe.py` | Four validations → `dswe_validation.md` + `dswe_vs_lidar.png`: phase-closure triangles, cross-pol consistency, SNOTEL anchor diagnostics, lidar bracketing/proxy comparisons |
| `rank_dswe_pairs.py` | ΔSWE vs BOTH lidar years for all pairs; gated ranking for snow-model precip input → `dswe_lidar_rank.{md,csv}` |
| `fetch_snotel_mcs.py` | Daily SWE+depth for Mores Creek Summit SNOTEL (637:ID:SNTL) via NRCS AWDB → `snotel_mcs_swe.csv` |
| `plot_snotel_flights.py` | Two-winter SNOTEL SWE plot with all UAVSAR flight and lidar dates → `snotel_swe_flights.png` |
| `phase_sd_correlations.md` / `.csv` | Screening results, all 22 pairs × 4 pols |
| `dswe_retrieval_log.csv` | Per pair×pol retrieval diagnostics (SNOTEL ΔSWE, anchor offset/window, deramp coefficients, coverage) |
| `dswe_validation.md`, `dswe_vs_lidar.png` | Validation report + scatterplots |
| `dswe_lidar_rank.md` / `.csv` | Correlation matrix vs both lidar years + the ranked top-5 (+ zero-change example) |
| `snotel_mcs_swe.csv`, `snotel_swe_flights.png` | SNOTEL record and timing figure |
| `deramp_pair8.png`, `unwrap_qc_pair*.png` | Deramp and unwrapping QC figures |
